# 河为什么不走直线

## 问题

河为什么总是弯弯曲曲，不走直线？

## 观众看完能说出来的话

1. 河里中间的水最快，贴着岸的最慢。
2. 河一有点弯，最快的水就被甩到外侧。
3. 外侧的岸被冲掉，冲下来的沙堆到内侧。
4. 外侧一直退、内侧一直长，弯就越来越大。
5. 弯大到两头碰在一起，河抄了近路，甩下的那道弯变成月牙湖。

## 开头第一眼

从太空俯冲到黄河，落到一段连续拐弯的峡谷里，真卫星图从河中间晕开：两头之间画一条直线，量出来约 20 公里；再沿河道画一遍，计数器滚到约 40 公里；
最后把两条线从地图上揭下来拉直，并排放在数字底下：河道正好是直线的两倍长。
主体（一条真的、绕得很厉害的河）第 0 帧就在画面上，第一句就是问题本身。

## 结尾落在观众身上

坐飞机靠窗往下看，窗外一条弯弯的河：陡的一边是外侧，有沙滩的一边是内侧。看完这条片子，观众自己就认得出来。

## 场景

| 场景 | 画面 | 字幕 |
|---|---|---|
| Dive | 地球推近到黄河 → 真实地形 → 卫星图晕开 → 直线和河道各量一遍 → 两条线揭下来拉直比长短 | 问题；两头约 20 公里；河道约 40 公里 |
| Straight | 俯视一段直河，流速箭头和水流亮点：中间快、两边慢 | 假如河是直的；中间最快、贴岸最慢 |
| Fling | 河慢慢弯起来，最快的那股水滑到外侧 | 一点点弯；最快的水被甩到外侧 |
| Section | 把弯道横着切开：水在弯里打旋，外侧岸被掏空塌下来，沙滚到内侧堆起来 | 外侧被掏空；沙堆到内侧 |
| Grow | 俯视，一道弯越拐越大，长成 Ω 形，两头碰到一起，河冲过去，甩下的那一圈变成月牙湖 | 越拐越大；抄近路；月牙湖 |
| Window | 飞机舷窗往下看，标出陡岸和沙滩 | 下次坐飞机；陡的是外侧、有沙滩的是内侧 |

## 事实表

| 说法 | 出处 / 怎么得到的 |
|---|---|
| 这段黄河两头直线约 20 公里，河道约 40 公里 | `scripts/terrain.py bends 110.30 36.62 110.56 36.80` 用 AWS Terrain Tiles 高程按水往低处流追出主河道，`scripts/satellite.py` 再把它贴到卫星影像水面的中线上，算得河道 40.0 km、两端直线 20.1 km（`public/sat/bends/main.json`）。屏上写「约」 |
| 开头的卫星图 | `scripts/satellite.py bends 110.30 36.62 110.56 36.80` 自动挑出的 Copernicus Sentinel-2 影像，2025-04-07 拍摄 |
| 直的河里，中间水面流速最快，贴岸、贴底最慢 | 河岸和河底的摩擦让水变慢，河流动力学的基本结论；Leopold & Wolman, *River Meanders*, GSA Bulletin, 1960 |
| 弯道里最快的水流偏向外侧；水在弯里打旋，表层冲向外侧、底层流回内侧 | 同上（弯道环流） |
| 外侧冲刷成陡岸，内侧淤积成沙滩（边滩） | 同上 |
| 弯越来越大，颈部被冲开后河道截弯取直，留下的旧弯成为牛轭湖（月牙湖） | 同上 |

没写进片子的：这段河弯的具体地名（查不到能核对的准确范围，所以只说「这段黄河」）；「离心力」「环流」「边滩」「牛轭湖」这些词（屏上用大白话）。
