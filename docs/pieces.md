# 组件

`src/pieces/` 里每个组件都调好了默认值：直接用就是成片的水准。每个组件在 `src/gallery/` 里有一段演示，
**那段演示代码就是用法的标准写法**，写之前先看对应的演示，`npm run gallery` 出的联系表里能看到它在屏上的样子。

所有组件都接收 `f`（场景帧号）和 `at`（从第几帧开始出现），坐标是画面像素（或者所在 `World` 的世界坐标）。
颜色不传就从外观里取。

下面每张卡写的是：拿它讲什么、观众看到什么、要调的那几个参数、容易做错的地方。

---

## 引擎自带

**字幕、版式、质感、转场**都在 `Film` 外壳里，场景里不用管：剧本里写的 `chapter`（左上章节）、`src`（右上出处）、
`badge`（顶部状态条，比如「公元前 256 年」）会自动出现；底部有按章节分段的进度条；背景的光、虚化光斑、颗粒、暗角全片铺好。

**镜头** `World` + `camAt`：在一个世界里推拉摇。`camAt(f, [[0, {x, y, z}], [cue(1), {x, y, z: 1.6}]])`，
x、y 是镜头对准的世界坐标，z 是放大倍数。`World` 的 `depth` 小于 1 的层动得少，用来做远景视差。

## 标注 · `Draw.tsx`

- `Tag`：一个点 + 引线 + 字，贴着被标的东西。先出点、再拉线、最后出字。`dx/dy` 是字相对点的位置；字放在空的那一侧，别压住主体。`sub` 写第二行小字。
- `Arrow`：从 a 画到 b，`bend` 让它带弧度。表示「往哪去」「推向哪」。
- `Ring`：手画感的圈，圈出「就是这里」。
- `Big`：画面里的大字（不是字幕）：一个关键数字、一个结论词。一个场景最多一处。

## 真实地形 · `Terrain.tsx`

讲一个真实的地方、一条河、一座山、一条路线。观众看到有光影的真山真水，河网像水一样一条条流出来。

- 先下载数据：`python3 scripts/terrain.py 名字 西 南 东 北`（经纬度范围，十几公里到两三百公里见方都行）。
  输出在 `public/terrain/名字/`，`main.json` 里有穿过这块地的主河道和它的长度、两头的直线距离——讲「绕了多远」直接用。
- `<World cam><Terrain name="名字" rivers={进度} flow={f}>{(meta, p) => 标注}</Terrain></World>`，`p(经度, 纬度)` 换成图上坐标，标注就钉在真实位置上。
- `riverMin` 调河网疏密，`dim` 压暗让标注更突出，`feather` 让地图边缘融进背景。
- 河网是从高程算的，大方向准，不一定和地图上的河道一模一样；要点名的地方先对照地图核实。
- 出处写「地形：AWS Terrain Tiles」。

## 卫星图 · `Satellite.tsx`

讲一个真实的地方时最有说服力的画面：真彩色卫星影像，河的颜色、沙滩、田块、村子、山脊都是真的。

- 先下载：`python3 scripts/satellite.py 名字 西 南 东 北`（要先 `pip3 install rasterio mgrs`）。它会在 Sentinel-2 公开影像里自动挑一景这块范围里没有云的，
  裁好、调好色，放到 `public/sat/名字/`。10 米一个像素：河道、田、街区看得清，单个房子看不清，所以范围十几到一两百公里见方最合适。
- 和同名同范围的 `Terrain` 逐像素对齐。放在同一个 `World` 里，先出地形，再用 `reveal`（0→1）让卫星图从 `from`（经纬度）那一点晕开盖满，就是「从地图落进真实世界」。
- `dim` 压暗让上面的线和标注更突出；`children` 和地形一样拿到 `p(经度, 纬度)`，标注钉在真实位置上。
- 默认不调色：真实的颜色就是它的价值。出处写 `meta.json` 里的 `credit`（「卫星影像：Copernicus Sentinel-2（拍摄日期）」）。
- 在影像上指认东西（「这是沙滩」「这是陡岸」）之前，先把那一块放大看清楚；10 米分辨率下拿不准的，就别在真影像上指，改用示意图讲。

## 地球 · `Globe.tsx`

「这件事在哪」「从这到那」「全世界」。一个有明暗、有大气光圈的地球，能转、能推近。

- `lon/lat` 是正对镜头的地方，`z` 越大越近；从 1 推到 50 以上，再叠化进 `Terrain` 和 `Satellite`，就是「从太空落到这里」（示范片的开头就是这样）。
- `Pin` 钉一个点，`Route` 沿大圆画航线，`GeoLine` 画河或海岸（世界大河用 `python3 scripts/rivers.py Huang` 下载到 `public/world/rivers.json`）。
- 只画海陆，不画国界。

## 剖面 · `Cutaway.tsx`

把一块东西切开看里面：皮肤、土、墙、电池、地壳、食物。斜着看过去的一块「蛋糕」，一层层长出来。

- `layers` 从上往下写，每层给厚度、颜色、纹理（`dots`、`grain`、`cells`、`fibers`、`stones`、`waves`）。
- `inside` 往剖面里放东西（一个伤口、一颗种子、一个气泡），`top` 往顶面上放东西，`open` 把上面掀开往里看。
- 每层的颜色按真实来（土是土色，肉是肉色），只有要讲的那一层用强调色或者发光。

## 流动 · `Flow.tsx`

水流、气流、血流、人流、热对流。上千个亮点顺着速度场流，快的地方亮、拉长、变成强调色，慢的地方暗。

- 写一个函数 `field(x, y) => [vx, vy]`（每帧走多少像素），常用的在 `fields` 里（`aroundCircle` 绕过圆柱、`channel` 河道、`vortex` 漩涡、`convection` 对流）。
- `mask` 返回 true 的地方不流（障碍物、岸）。同一个 `id` 的流线只算一次。
- 看清「哪里急、哪里缓」靠的是快慢反差，速度场里快慢要拉开至少三倍。

## 分子 · `Molecule.tsx`

讲到「东西里面的小颗粒」：水为什么会被微波加热、盐怎么溶进水、二氧化碳怎么吸热。原子是有光泽的球，按真实的键长、键角摆好。

- `kind` 选现成的（`H2O`、`CO2`、`O2`、`N2`、`CH4`、`NaCl`），或者用 `atoms` 自己摆。`size` 是 1 埃多少像素：单独讲一颗用 120–160，一大片用 25–35。
- `rot` 在画面里转，`spin` 绕竖轴转（翻面）；`charges` 标出哪头带正电、哪头带负电（只对水这种一头大一头小的分子有意义）；`glow` 让它发光。
- 它画在 svg 里：一大片分子放进同一个 `<svg>`，先放一个 `<AtomDefs />`，每颗加 `defs={false}`；单独一颗放在普通层里用 `MoleculeSvg`。
- 一大片分子时，同一时间只让一样东西变（先一起转向，再一起乱撞），不要满屏都在乱动。

## 热成像 · `Heat.tsx`

温度看不见，就涂成颜色。加热、散热、体温、保温、冷热不均都用它。

- `HeatField` 的 `field(u, v)` 返回每个位置此刻的温度（0–1），返回负数的地方透明（形状外面）。颜色用的是 `heat()` 温度色阶，四种外观通用。
- `legend` 画色标（两头写真实温度），`frame` 画红外相机的取景角，`clip` 给形状的轮廓（svg path），边缘就是圆滑的。
- 颜色要是算出来的：`conduct()` 是一个现成的热传导小模拟（给形状、给热源、走几步），把结果按步数存下来，场景里按帧在几步之间插值；`sampleGrid()` 把网格变成 `field`，格子之间平滑过渡。

## 质感 · `Material.tsx`

自己画一样东西（微波炉、碗、杯子、手机、零件）时给形状上材质：`<Mat id kind color />` 放进 `<defs>`，形状用 `fill="url(#id)"`。
`kind` 有 `metal`、`plastic`、`ceramic`、`glass`、`matte`、`liquid`。再加 `ContactShadow`（落在地上的影子）和 `Gloss`（左上角的高光），东西就立起来了。

## 点阵 · `Crowd.tsx`

让观众「数得见」：1000 个人里有几个、两组差多少。一个点（或一个小人）代表一个人、一件事、一万块钱。

- `unit` 选 `dot` / `person` / `square`。`group(i)` 给每个点分组，到 `groupAt` 时点会跑进各组，比例是「看出来」的。
- `hi(i)` 让某些点发光：「就是这几个」。
- 数量上千时用 `dot`；要观众感到「这是人」时用 `person`，几百个以内。

## 逐步演算 · `Choreo.tsx`

把一个过程一步一步真的演出来：排序、配对、排队、淘汰、传染、投票。

- 先用代码把每一步每个东西的位置、颜色、字算出来（真的算一遍，不要手摆），交给 `steps`；它负责两步之间平滑挪过去，错开先后，带一点「拿起放下」的弧度。
- `layout.row / col / grid / circle` 给常用的排法。`render` 换掉默认的圆形筹码，画成任何东西。
- 屏上每个数都应该能从上一步算出来。观众会发现「这是真的在算」。

## 年份和数字 · `Years.tsx`

- `Odometer`：里程表式滚动的数字（年份、人数、钱）。值是小数时会一位一位翻上去，最后几位真的在「转」。
- `TimeRibbon`：一条会走的时间轴，`eras` 是一段段时代，`events` 是点，游标停在 `now`。
- 「年份一路往前推」的讲法：顶部 `badge` 或角上 `Odometer` 滚年份，画面跟着时代换。

## 大小 · `Scale.tsx`

- `SizeUp`：一排方块（或圆），面积按真实数值算，镜头从小的一路拉远到大的，小的最后缩成一个点。`now` 是镜头对准第几个（可以是小数）。
  差几个数量级的东西都能放下。`draw` 可以把方块换成真东西的样子。
- `LogLine`：一把对数尺，从 10⁻⁹ 到 10²⁶，游标滑过去一路标出各个东西。

## 图表 · `Chart.tsx`

- `Bars`：横条。数值每帧变时条会自己重新排序、平滑超车，适合「排名怎么变」「模拟跑起来以后谁多谁少」。
- `Columns`：竖柱，少量几根按时间排的。
- `Plot`：曲线从左往右画出来，线头的亮点带着当前数值，`refs` 画参考线（理论值）。适合「慢慢收敛到」「越来越快」。
- 数据是真的就写出处；是模拟出来的，就在代码里真跑一遍（用 `hash` 当随机数，结果每次一样）。

## 分叉 · `Tree.tsx`

概率、决策、因果链、淘汰赛。从左往右一层层长出来，`weight` 让枝的粗细等于概率，`hi` 点亮一条路，其他变暗。

## 出处 · `Source.tsx`

开头放一个反直觉的结论时，一页「纸」滑进来：刊名、年份、标题，关键那句被荧光笔划出来。观众知道「这不是瞎说的」。
只写真实存在、查得到的出处；`quote` 可以是中文转述，但意思必须和原文一致。

## 照片 · `Photo.tsx`

真实照片、档案图、卫星图。慢慢推拉（`from` → `to`），`spot` 打一束光圈出要看的地方，`grade` 把颜色往外观上靠，`print` 做成冲印照片。
只用能公开使用的图，`credit` 写作者和协议。

## 展台 · `Stage.tsx`

主角第一次登场、或者要观众盯着它看的时候：顶上一束光、底座、玻璃罩、铭牌，像博物馆展品。东西本身由 `children` 画。

## 人 · `Figure.tsx`

- `Figure`：真人比例、有明暗。`mood` 有 9 种表情，`pose` 有 10 种姿势，`from` + `poseT` 让姿势平滑过渡；`facing` 转身（`'back'` 是背影：排队、看远处、走开），`walk` 走路，`look` 眼睛看向哪，`hold` 手里拿东西。会眨眼、会呼吸。
- `People`：一排人，长相按 `seed` 自动错开。
- 背景里的人用 `dim` 压暗，主角就跳出来了。

## 组件不够用时

讲「东西是怎么工作的」，主角多半是一样具体的东西（微波炉、心脏、锁、发动机），组件库里不会有，要自己画。
这是最花时间、也最决定成败的部分：先在一个场景里把它画好，画到放大到半个屏也经得起看，再让它动。
画法：拆成几块简单形状，每块上 `Mat` 材质，加 `ContactShadow` 和 `Gloss`；要透视里面就把外壳变半透明（`opacity` 0.3–0.5），里面的零件照常画。

自己写组件放在 `src/film/scenes/` 里。示范片的 `River.tsx` 就是一个为这条片子专门写的组件：
用正弦曲线生成河道、算出弯顶和最窄的「颈」、按横向位置给水流不同的速度，再画上深浅、沙洲、岸边的树。
写法照着 `src/pieces/`：颜色从 `useLook()` 取，字号用 `SIZE`，动画只由 `f` 决定。
